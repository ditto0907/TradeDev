# Gap Analysis Skill 设计方案 v1（定稿）

> **状态**：Current — 设计定稿，实现方案见 [v1_gap_analysis_implementation_design.md](v1_gap_analysis_implementation_design.md)（编码进行中）
> **日期**：2026-08-31
> **相关**：[../strategy/v2_strategy_research.md](../strategy/v2_strategy_research.md)（P3 信号化回流）

## 1. 定位

**名称**：`gap-analysis`（与 `market-cycle-analysis` / `bar-by-bar-analysis` 并列，共享词汇表与数据访问约定）

**核心问题**（每次输出必须回答）：
1. 顺势方**创造了哪些缺口**？质量如何（大小、位置、类型）？
2. 顺势方**能否保持缺口**？（回调是否进入缺口区、进入多深、是否被拒绝）
3. 逆势方**能否回补缺口**？回补后是反转还是只是 TR？
4. **谁被套住了**？被套方的止损位在哪（= 下一个燃料点）？

区别于 market-cycle-analysis：那个 skill 回答"现在是什么周期"，本 skill 回答"**多空双方的实力对比与承诺程度**"——缺口是 Brooks 体系里衡量 urgency/conviction 最直接的证据。

**v1 取向（已确认）**：放弃经典开盘缺口叙事（G1 Opening Gap / G2 Bar Gap 出局），聚焦**结构性缺口（G3/G4/G5）**，即不做"跳空回补"的传统分析，专注衡量盘中趋势方的结构性承诺强度。

## 2. v1 检测范围与机械化程度

| 类型 | 机械定义（5min RTH） | 可纯机械检测？ | 需要的上下文 |
|------|---------------------|:--:|------|
| **G3 Micro Gap** 微缺口 | bull: `low(i+1) > high(i-1)`（i 即 BO 棒）；bear 对称 | ✅ 完全机械 | 无——该条件成立本身就定义了 i 是 BO 棒 |
| **G4 Breakout Gap** 突破缺口 | 突破关键位 L 后，后续回调极值始终不触及 L | ⚠️ 半机械 | 关键位清单：PDH/PDL/PDC（1D 取）、OR 高低点（机械）、swing 高低点（机械）、TR 边缘（LLM 判定） |
| **G5 EMA Gap Bars** 均线缺口棒 | 连续 N 根 `low > EMA20`（bull）/ `high < EMA20`（bear），≥20 根 = 强趋势阈值 | ✅ 完全机械 | EMA20 序列 |

> 注：虽然开盘缺口出局，**PDC/PDH/PDL/隔夜区间仍必须获取**——它们是 G4 的关键位来源，1D `trade_date` 防坑规则照旧（按 `trade_date` 字段选前一交易日，严禁 astimezone 1D 时间戳）。

### 三类缺口在记分板中的分工

```
G3 → 逐次推进的 urgency 证据（微观强度）
       ├─ 趋势早段的 G3 = BO 确认
       ├─ 趋势中段的 G3 = Measuring Gap → 投影 MM 目标
       └─ 远离 EMA + 第3腿后的 G3 且数根内被补 = Exhaustion 警报
G4 → 结构层控盘证据（回调不回踩突破位 = 逆势方连试探资格都没有）
G5 → 趋势持续性计量（gap bar 连续计数 = 趋势"心跳"，计数中断 = 第一次减速）
```

### 定性第二层（LLM 层，非机械）

同一个物理缺口，含义由它在趋势中的位置决定：

```
缺口出现的位置（腿计数 + EMA 距离）
├─ 趋势起点（刚离开 TR / OR）      → Breakout Gap（出生）
├─ 趋势中段（第 1-2 腿之间）        → Measuring Gap（量度缺口）
│     └─ MM 投影：缺口中点 = 全程中点 → 目标价
└─ 趋势末端（第 3+ 腿 / 远离 EMA）  → Exhaustion Gap（衰竭缺口）
      └─ 特征：创造后几根内被回补 → 反转警报
```

需要腿计数、EMA 拉伸度、大棒计数作为上下文输入——与 market-cycle-analysis 的 "BO vs Climax" 决策树同构。

## 3. 缺口生命周期状态机（核心引擎）

每个缺口从创建起逐根跟踪，状态迁移本身就是多空实力的语言：

```
CREATED（创建）
  │  逆势方价格进入缺口区（未过半）
  ├──────────────► TESTED（被测试）
  │                  │  回撤超过缺口 50%
  │                  ├──────────► PARTIAL（半补）
  │                  │              │  触及缺口远端 / 突破位 L
  │                  │              ├──────► CLOSED（回补 = 磁铁达成，不构成反转结论）
  │                  │              │          │  收盘越过缺口起源位
  │                  │              │          └──────► REVERSED（反转确认，顺势方被套）
  │                  │  长影线拒绝、收回缺口之外
  │                  └◄─────────── DEFENDED（防守成功，逆势方被套）
  │
  └─ N 根之内无人测试 ────► HELD（持续持有 = 顺势方完全控盘）
```

**回补双层判定（已确认）**：
- **触及**缺口远端/突破位 → `CLOSED`（磁铁效应，不等于反转）
- **收盘**越过缺口起源位 → `REVERSED`（顺势方被套确认，failed BO 逻辑启动）

G5 的"状态"即连续计数与首次 EMA 触碰事件（首次触碰 = Gap Bar setup 顺势入场点）。

### 状态迁移的交易含义表

| 事件 | 顺势方 | 逆势方 | 行动含义 |
|------|--------|--------|---------|
| 缺口创建 ≥阈值 | +强承诺 | 犹豫/被套 | 按 BO 处理，等 FT |
| 首次回调不触及缺口 | +极强 | 逆势试探失败被套 | 回调即 H2/L2 顺势入场 |
| TESTED→DEFENDED（长影线拒绝） | +确认 | 二次被套 | 缺口边缘 = 已验证 S/R |
| 1 小时内 CLOSED | 早期追入者被套 | +夺回主动权 | 大概率 TR 日，改做区间边缘 |
| 尾盘才 CLOSED | 中性 | 磁铁效应而已 | 不构成反转证据 |
| CLOSED→REVERSED | 被套（燃料） | +趋势反转 | Failed BO → 反向 MM |
| 同向缺口堆叠（2+ 个未补） | 趋势日确认 | 无力 | 只顺势，不逆势 |

**时间维度**：缺口在**第一小时末（前 12 根）**的存活状态是日型分水岭。HELD 检查点：创建后第 6 / 12 / 18 根（30min / 1h / 1.5h）。

## 4. 多空记分板（结论层）

把所有缺口事件汇总成双方证据清单，落到 Always-In 与日型假设：

```
• 顺势方证据（每条附具体缺口编号与价格）:
    - 创造缺口数 / 总 ticks
    - 存活缺口数、最老缺口已存活 N 根
    - 回调测试被拒次数（DEFENDED 次数）
    - G5 gap bar 连续计数
• 逆势方证据:
    - 回补缺口数、回补耗时
    - 测试深度逐次加深（侵蚀迹象）
    - 顺势方创造缺口失败（缺口当根/次根即补）
• 被套判定: 哪一方、在什么价位、止损堆在哪里（= 磁铁）
• 结论: AIL/AIS/中性 + 日型假设 + 当前可执行的读法
```

## 5. Skill 交互与流程

**触发词**：gap、缺口、跳空、回补、gap fill、"缺口分析"、"谁被套了"

**参数**：`<symbol> <date> (+ optional cutoff time)`，如 `MES 2026-05-29 up to 11:00`

**流程**（严格无后视偏差，沿用现有约定）：

1. 取 1D bars → 按 `trade_date` 选前一交易日 → PDC/PDH/PDL
2. 取隔夜 ETH 5min → 隔夜 TR 区间（G4 关键位来源）
3. 取当日 RTH 5min 至 cutoff，计算 EMA20 与逐棒指标
4. **检测层**：扫描 G3/G4/G5，建缺口清单（编号、类型、方向、区间 [底, 顶]、大小 ticks、创建棒#）
5. **跟踪层**：对每个缺口逐棒跑状态机，记录关键迁移事件
6. **定性层**：结合腿计数/EMA 距离定性 BO/Measuring/Exhaustion；Measuring gap 投影 MM 目标价
7. **结论层**：多空记分板 → AIL/AIS → 日型假设 → 可执行读法
8. **回写**：POST `/api/skill/analysis` 标注

### 图表标注策略（已确认：只标注存活缺口）

| 缺口元素 | 标注类型 | 示例 |
|---------|---------|------|
| 存活 G3 缺口区 | `range`（绿/红半透明） | "G3 Bull Gap 6412.25–6415.00" |
| 存活 G4 突破位 L | `hline` dashed | "G4 defended @ 6408.50" |
| G5 触发 20 根阈值 | `label` | "20 EMA gap bars — strong trend" |
| REVERSED 事件（例外） | `label` | "G3 Reversed → bulls trapped"（被套证据是交易级信息） |
| 昨日未补缺口 | `hline`（可选） | 属存活缺口，符合"只标存活"原则 |

缺口一旦 CLOSED → 从图上消失，只留在文字清单。

### 输出结构

```
• 头部: 昨日未补缺口提示（一行）+ 关键位清单（PDH/PDL/PDC/OR/隔夜区间）
## 缺口清单表: # | 类型 | 方向 | 区间/位 | ticks | 创建棒 | 状态 as of HH:MM | 关键事件
## G5 心跳线: 当前连续计数 / 今日最大计数 / EMA 触碰事件列表
## 逐缺口叙事: 只详述记分板权重前 3
## 多空记分板 → AIL/AIS / 日型假设 / 被套方与其止损堆 / 可执行读法
```

## 6. 量化参数（默认值，写死在 SKILL.md，可被用户覆盖）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| tick size | MES/MNQ 0.25, MGC 0.1, NK225MC 5 | 按 symbol 查表 |
| G3 显著阈值 | ≥ 2 ticks 或 ≥ 15% ATR(20 bars) | 1-tick 缺口只在成簇出现时报告 |
| CLOSED 判定 | 触及远端/突破位 | 双层判定第一层 |
| REVERSED 判定 | 收盘越过起源位 | 双层判定第二层 |
| TESTED 判定 | 回撤进入缺口区任意深度 | |
| PARTIAL 判定 | 回撤 > 缺口 50% | |
| HELD 检查点 | 创建后第 6 / 12 / 18 根 | 30min / 1h / 1.5h，对应第一小时规则 |
| G5 强趋势阈值 | ≥ 20 根 | Brooks 20-gap-bar 规则 |

## 7. 边界情况与防御设计

1. **数据缺口 ≠ 价格缺口**：G3 检测前必须验证 `time(i) - time(i-1) == 300s`；跨时段（16:00→次日09:30）、数据空洞（后端 `find_gaps` 的 `data_gap`）一律不算价格缺口。
2. **半日/假日**：不用固定棒数推时间，一律用时间戳；检查点按"创建后第 N 根"计数自然适配。
3. **多缺口管理**：不合并重叠缺口（各自独立跟踪），叙事层只详述记分板权重前 3，其余进清单表。
4. **跨日历史缺口（已确认 v1 范围）**：只输出"昨日是否留下未补缺口"一行提示 + 可选一条 hline，不做完整多日跟踪。
5. **盘中任意时点调用**：即使 13:00 才问，也必须从 09:30 取全量数据重建所有缺口完整生命周期——状态机没有"从中间开始"。
6. **无缺口的日子**：明确输出"今日无显著缺口，双方均无 urgency 证据 → 本身就是 TR 日证据"——零检出也是信号。
7. **Cutoff 纪律**：沿用 `to_dt` 硬约束，输出标明"截至 HH:MM 的状态"，存活缺口标 "OPEN as of HH:MM"。

## 8. 实施分期

| 阶段 | 内容 | 理由 |
|------|------|------|
| **P1** | 纯 SKILL.md（LLM 直接调 `/api/skill/bars` 完成检测+跟踪+叙事） | 零后端改动，与 bar-by-bar 同模式，最快验证方案价值 |
| **P2** | 后端加机械检测端点 `GET /api/skill/gaps`（或 MCP tool），返回缺口清单+生命周期事件流；LLM 只做定性与叙事 | 状态机逐棒跟踪是 LLM 最易算错的部分；G3/G5 完全机械，性价比高；可复用 `strategy/signal_detector.py` 的 GAP_EPS 思路 |
| **P3** | 接入 strategy-research：缺口特征（存活时长、回补速度）写入 Orders 表作信号列；回测统计"缺口存活 N 根后回调的胜率"校准记分板权重 | 把经验规则变成有数据支撑的概率 |

## 9. 已确认的决策记录

| 决策点 | 结论 |
|--------|------|
| v1 缺口类型范围 | **G3 + G4 + G5**（G1 开盘缺口、G2 bar gap 出局） |
| 回补判定 | **双层**：触及 = CLOSED，收盘越过起源位 = REVERSED |
| 图表标注 | **只标存活缺口**（REVERSED 事件 label 例外） |
| 跨日缺口 | **v1 只提示昨日未补缺口一行** |

## 10. 依赖的现有基础设施

- `GET http://localhost:8000/api/skill/bars` — 5min + 1D，RTH/ETH，`from_dt`/`to_dt` ET 字符串，1D 带 `trade_date`
- `POST http://localhost:8000/api/skill/analysis` — 标注类型 range / hline / label
- 词汇表与防坑规则：复用 `market-cycle-analysis` SKILL.md（缩写表、trade_date 约定、无后视偏差）
- 1H 不入库：需要时从 5min ETH 聚合（同 bar-by-bar 约定）
